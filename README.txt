MELA GHUMO — FRONTEND WEBSITE

Files:
- index.html: website content
- style.css: responsive modern design
- script.js: interactive features

How to run:
1. Extract the ZIP file.
2. Open index.html in Chrome/Edge/Firefox.

Working frontend interactions:
- Search by mela name/city/keywords
- Filter by category chips or dropdown
- Favourite/save buttons (temporary, in current page only)
- Mela details modal
- Mobile navigation menu
- Newsletter form demo confirmation
- Responsive layout for mobile and desktop

Limitations:
This is frontend-only. It does not use a backend or database. Favourites and newsletter entries are not permanently stored or sent. Mela listings are sample/demo content; verify real event dates and details before visiting. A photo in the hero section loads from Unsplash and requires internet access.
